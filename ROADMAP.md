# FDL Roadmap

This is a future-facing backlog, captured July 30, 2026. It records product
intent only; it does not authorize implementation on its own.

## Intended sequence

1. Document and demonstrate every modifier sufficiently.
2. Refactor the Lit components into framework-independent, bare-metal custom
   elements with no dependency on Lit.
3. Build a website that brings together the complete documentation and examples.
4. Build full-page scenarios that combine multiple controls and fields using a
   variety of modifiers. One scenario should reconstruct ACH payments while
   incorporating multi-jurisdictional child-support rules.
5. Build a parallel component implementation based on React rather than custom
   elements.
6. Include a page that clearly articulates FDL's design philosophy.
7. Include a page explaining how the repository was rehabilitated and how the
   website and its content were stood up quickly.

## Portfolio objective

Develop FDL into a strong portfolio piece demonstrating platform architecture
and AI-assisted development.
